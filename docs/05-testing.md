## 2. Набор данных

20 конфигураций в `data/synthetic/`: 12 воспроизводят признаки захвата учётной
записи, 8 — легитимные настройки, которые не должны давать срабатываний.
Разметка хранится в `data/synthetic/labels.json` рядом с кейсами.

Покрытые сценарии: внешняя пересылка, forward-and-delete, сокрытие в папке,
фильтр по финансовым словам, правило из ночной сессии без MFA, правило из
зарубежной сессии, внешнее делегирование, длинный список правил с одним
вредоносным. Легитимные: автоответ, сортировка рассылок, пересылка внутри
компании, делегирование коллеге, фильтр по счетам без действий, большая
конфигурация, пустой ящик.

## 4. Дефекты, найденные тестами

| Дефект | Как проявился | Исправление |
|--------|----------------|-------------|
| Ложное срабатывание на легитимном правиле | Кейс case-16: фильтр по слову «договор» с перемещением в папку «Важное» давал 15 баллов, хотя письма не скрываются | Детектор финансовых слов теперь требует пересылки или фактического сокрытия, а не любого перемещения |
| Неинформативное пояснение | При сессии без MFA причина попадала в поле evidence, но не в текст пояснения | Проверка в тесте переведена на evidence, пояснение переписано |
| Недетерминированные данные | Генератор использовал `hash()` для IP-адреса, набор менялся между запусками | Заменено на устойчивую функцию от идентификатора сессии |

## 5. Чего тесты не покрывают

1. Реальные экспорты Google Workspace, Яндекс 360 и Microsoft 365 — формат
   проверялся на синтетике; расхождения возможны.
2. Правила, созданные вне почтового ящика (шлюз, сторонний сервис).
3. Нагрузку выше лимитов: 500 правил — сознательное ограничение, а не
   протестированный максимум.
4. Поведение интерфейса под нагрузкой и на мобильных экранах.
5. Юзабилити-тест с реальным пользователем без ИБ-бэкграунда — запланирован на
   этап после защиты.

## 6. Как воспроизвести

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

pytest -q                       # 142 теста
python -m app.cli --input data/synthetic/case-10.json
python scripts/gen_configs.py   # пересоздать набор
streamlit run app/ui.py         # веб-интерфейс
```
